# 00 总览与路线图 —— 从零搭一个生产级 Agent(完整教程)

> 本教程与项目同生:每完成一个阶段,向 docs/learning/ 追加对应章节。
> 它比 README 详细得多:README 是地图,这里是旅程——每阶段的设计理由、dsh 源码参照、Python 实现、验收测试、手动操作、踩坑记录。
> 每章配图:架构/数据流图与界面效果 mockup(由 GDI+ 渲染);本地跑起来后可替换为真实截图。

## 你将学会什么

- 一个"可上生产"的 agent 由哪些模块构成:7 个核心模块 + 审计层 + 3 件基础设施(SQLite/Qdrant/Redis)
- dsh 的"脊梁"是什么、"扩展性机器"是什么,为什么砍后者、留前者
- 每条铁律对应的工程机制:append-only 日志、schema 版本 fail-closed、回放测试、审批持久化、完整结果上限
- 一个 agent 的完整生命周期:契约 → 存储 → 摄取 → 循环 → 护栏 → 可观测 → 上线

## 前置知识

- Python 3.12+ 基础(asyncio 加分,不是必需)
- 用过至少一个 LLM API(不要求懂 dsh)
- 基本 SQL(会 SELECT/INSERT 即可)
