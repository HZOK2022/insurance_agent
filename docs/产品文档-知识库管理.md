# 知识库管理功能 —— 产品说明

## 为什么要做

当前保险知识库的管理方式只有命令行脚本（`ingest_kb.py` / `rebuild_qdrant.py`），管理员要增删改查知识库必须登录服务器敲命令，操作门槛高、不直观。

知识库管理功能就是让管理员**通过 Web 页面就能完成所有操作**，不需要接触命令行。

## 目标用户

- **管理员**：负责维护知识库内容（增删改查）

- **普通客服**：只能使用问答，看不到知识库管理入口，也不能通过 API 操作

## 功能清单

### 1. 文档列表

管理员登录后，可以看到知识库里所有文档的列表，每篇文档显示：

- 文档 ID（文件名）

- 文档类型（txt/pdf/docx/xlsx）

- 保险类别（医疗险/重疾险/意外险）

- 分块数（该文档被切成了多少段）

- 更新时间

支持分页浏览，不限制每页显示条数。

### 2. 查看文档内容

点击某篇文档，可以查看它的所有分块（chunks），每个分块显示：

- 分块 ID

- 所属版本

- 章节名

- 内容预览（前 200 字）

支持分页浏览。

### 3. 上传新文档

管理员可以直接在界面上传文档内容，填写：

- 文档内容（文本粘贴）

- 文档 ID（唯一标识，如 "尊享e生2025条款"）

- 版本号

- 文档类型

- 保险类别

- 标题

提交后系统自动完成**切块 → 写入知识库 → 建立向量索引**，整个过程不需要人工介入。

### 4. 删除文档

管理员可以删除整篇文档，删除后：

- 知识库的原文被移除

- 向量索引同步清除（检索结果里不会再出现该文档）

- 已产生的历史问答记录不受影响（引用过该文档的老回答仍然可以查看）

### 5. 重建索引

如果向量索引出了问题（比如删除后残留、配置变更），管理员可以一键重建。系统会从知识库原文重新生成所有向量索引，像格式化重装系统一样，保证索引和原文完全一致。

## 用户角色划分

| 角色   | 能做什么       | 不能做什么       |
| ---- | ---------- | ----------- |
| 管理员  | 问答 + 知识库管理 | —           |
| 普通客服 | 仅问答        | 增删改知识库、重建索引 |

登录时系统自动判断角色，普通客服的界面不会出现知识库管理入口，直接调用 API 也会被拒绝。

## 使用流程

### 管理员首次使用

1. 管理员用播种的账号密码登录
2. 侧边栏出现"知识管理"入口
3. 进入后看到文档列表
4. 可以上传文档、删除文档、重建索引

### 日常使用

- 新条款上线 → 管理员上传文档

- 条款下架 → 管理员删除文档

- 知识库异常 → 管理员点"重建索引"

## 不做的范围

- 不支持在线编辑文档内容（只能整篇上传或整篇删除）

- 不支持批量上传（一次只能传一个文件）

- 不支持文档版本管理（旧版本直接覆盖，引用不受影响）

- 不记录操作日志（知识库管理操作只在应用日志中留痕）

## 非功能要求

- 所有操作应该在页面上实时反馈结果（成功/失败/进度）

- 删除操作需要二次确认

- 重建索引需要提示"此操作可能耗时较长"

- 非管理员无法感知知识库管理功能的存在
