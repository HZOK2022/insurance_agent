黄金法则:SQLite = 事实源 · Qdrant = 可重建的派生索引 · Redis = 可丢失的加速层 —— 易失层全空,系统照常跑
SQLite 事实源
  • 会话日志 · trace · token 账本
  • WAL · append-only · 单写者
  • schema 版本号:不认识就拒绝启动
使用者:④ ⑥
Qdrant 派生索引
  • 向量知识库 · 稠密 + 稀疏混合检索
  • 检索查询改写:改写搜索词,让检索更准
  • 切块 → 嵌入 → upsert 写入管道
  • payload:来源 / 租户 / 权限 / 模型标签
使用者:⑧(可从源文档全量重建)
Redis 易失加速
  • 嵌入缓存 · 幂等工具缓存(TTL)
  • 限流 / 预算 · 锁与热态
  • 不缓存 LLM 补全与被依赖的读
使用者:② ③ ⑦(清空即恢复)
四条铁律
① 模型可见 ⇔ 已记录:进模型请求的一切(含检索片段)都落 SQLite,可离线重放  |  ② 易失层可随时清空:Redis / Qdrant 全空,系统照常跑;事实源只有 SQLite
③ 工具结果 = 不可信输入:Schema 校验 · 截断 · 防注入;危险操作先审批  |  ④ 上限加在完整结果上:步数 / token / 字节三重上限,防失控循环
